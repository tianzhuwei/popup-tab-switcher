## 简介

一个让标签页切换更便捷的浏览器扩展。它会记住标签页的访问顺序，让你无需使用鼠标就能在最近访问的标签页之间快速切换。

## 主要功能

- **快速切换**: 按快捷键（默认 `Alt+Y` 或自定义）在最近标签间往复。
- **置顶标签**: 点击图标旁的小图钉，将重要页面固定在顶部。
- **直接关闭**: 在弹窗列表中直接点击 ✕ 关闭标签，无需先切换过去。
- **现代界面**: 完美适配深色/浅色主题，支持背景模糊效果。

## 使用方法

1. 按 `Alt+Y`（或自定义快捷键）打开标签切换弹窗。
2. 继续按快捷键或使用方向键/鼠标选择标签。
3. 松开快捷键或点击，立即切换到选中的标签。
4. **鼠标悬停**: 鼠标停留在弹窗上时，弹窗将保持开启，方便进行置顶或关闭操作。

## 开发与安装

```bash
npm install
npm run build:dev
```

然后在 Chrome 扩展程序页面（`chrome://extensions/`）开启“开发者模式”，点击“加载已解压的扩展程序”，选择 `build-dev` 目录即可。

## 限制

- 受浏览器安全限制，Chrome 网上应用店页面及部分系统内置页面（如设置页）无法显示弹窗。
- 若需在本地文件 (`file://`) 页面使用，请在扩展管理页开启“允许访问文件网址”。
