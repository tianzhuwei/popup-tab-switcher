## 简介

一个让标签页切换更便捷的浏览器扩展。它会记住标签页的访问顺序，让你无需使用鼠标就能在最近访问的标签页之间快速切换。

## 主要功能

- **快速切换**: 按快捷键（默认 `Alt+Y` 或自定义）在最近标签间往复。
- **置顶标签**: 点击图标旁的小图钉，将重要页面固定在顶部。
- **直接关闭**: 在弹窗列表中直接点击 ✕ 关闭标签，无需先切换过去。
- **右键关闭**: 在网页右键菜单中选择“关闭标签页”，关闭该页面。
- **新建标签**: 点击弹窗底部的小加号打开新标签页。
- **截图预览**: 在 Appearance 中开启 Tab previews 并授权后，选中标签时显示最近截图；关闭 Auto previews 后继续缓存，有截图的网站图标显示细框和叠片角标，悬停图标时显示大图。预览会自动选择列表侧面或上下方的可用空间。
- **智能排序**: Smart ranking 默认关闭，可分别保存 Jev 和阿里云的接口地址与 API Key，切换服务商时恢复各自的配置。结合标签打开来源链、各标签的访问与双向切换统计，区分同域名下的不同页面；关联数据仅在当前浏览器会话内保留，关闭智能排序时清空。Test 仅用示例数据检查连接，不会保存配置或开启排序；Save 保存当前开关及两个服务商的配置。
- **现代界面**: 支持自动、浅色和深色主题；增强视觉效果默认关闭，可在设置中开启。

## 使用方法

1. 按 `Alt+Y`（或自定义快捷键）打开标签切换弹窗。
2. 继续按快捷键或使用方向键/鼠标选择标签。
3. 按 Enter/空格或点击目标标签确认；未启用“Stay open”时，松开快捷键也会切换。
4. **鼠标悬停**: 鼠标停留在弹窗上时，弹窗将保持开启，方便进行置顶或关闭操作。

截图只在实际浏览普通网页时低频采集；没有可用截图的标签不显示预览框，网站图标也不显示预览标记。截图使用扩展本地缓存，每个标签保留最新一张，最多 30 张且不超过 10 MB，并为其他设置预留存储空间；更新或重新加载插件时保留，浏览器启动时清空。关闭标签或 Tab previews 总开关时清理，关闭 Auto previews 不清理，不长期保存截图文件。窗口过小时优先保留列表操作区域。

## 开发与安装

```bash
npm install
npm run build:dev
```

开发包的输出目录由 `webpack.config.js` 配置，当前为 `/Applications/01-CrhomeExtension/TabPop`。在 Chrome 扩展程序页面（`chrome://extensions/`）开启“开发者模式”，点击“加载已解压的扩展程序”，选择该目录即可。开发构建默认包含自动重新加载插件的钩子。

`npm run build:prod` 会生成带时间戳的发布目录及 ZIP 包。单元测试和 TypeScript 检查命令分别为 `npm test`、`npm run test:ts`。`lint` 命令保留，但目前没有项目规则配置。

## 限制

- 受浏览器安全限制，Chrome 网上应用店页面及部分系统内置页面（如设置页）无法显示弹窗。
- 若需在本地文件 (`file://`) 页面使用，请在扩展管理页开启“允许访问文件网址”。
